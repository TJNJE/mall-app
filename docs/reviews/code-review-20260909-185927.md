## Findings

### F1-未修复-低-Modal focus-trap 未实现

- 位置：src/common/components/ui/Modal.tsx
- 场景：对话框打开时 Tab 可将焦点移出对话框到背景元素（WCAG 2.4.3 部分）
- 直接证据：Modal 无 focus-trap 逻辑（仅 ESC/overlay 关闭）
- 影响：键盘用户可聚焦不可见元素；aria-modal="true" 声明了模态但焦点未锁定，不完全一致
- 建议：引入 focus-trap 逻辑（自实现或 focus-trap-react）；配合 inert 属性冻结背景
- 修复风险：低；严重程度：低；裁决：deferred-with-owner（a11y 深化批次）

### F2-未修复-低-暗黑全站适配未完成（plan 预期内）

- 位置：除 Header/ProductListPage 标题外的组件仍为硬编码灰阶
- 场景：暗黑下 Cart/Order 等页面仍为亮色卡片
- 直接证据：plan 修订 2 显式将「全站适配」defer
- 影响：暗黑模式体验不完整（首批可演示机制）
- 建议：后续按页面批次推进语义 token 迁移
- 修复风险：低；严重程度：低；裁决：deferred-with-owner（plan 修订 2 预期）

### F3-未修复-低-.storybook 配置文件排除出 eslint

- 位置：eslint.config.js globalIgnores
- 场景：main.ts/preview.ts 不被 lint
- 直接证据：两文件不在任何 tsconfig project 内，projectService 报 file not found
- 影响：配置文件失去类型级检查（由 SB build 隐式验证）
- 建议：如需恢复，为 .storybook 建独立 tsconfig 并从 ignores 移除
- 修复风险：低；严重程度：低；裁决：accepted-as-is
