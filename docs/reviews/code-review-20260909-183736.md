- 位置：vite.config.ts cspInjectPlugin 策略
- 场景：后续配置 VITE_SENTRY_DSN 后，Sentry 事件上报（connect-src 'self'）将被 CSP 拦截
- 直接证据：策略中 connect-src 仅 'self'；代码注释已标注需追加
- 建议：接入真实 Sentry 时在 connect-src 追加 `https://*.sentry.io`（或自托管域名）
- 修复风险：低；严重程度：低；裁决：deferred-with-owner（依赖真实 Sentry 凭据，Phase 2 deferred 项联动）
